# Yellow Ribbon Back Office

An administration panel for managing therapists and appointments. The project uses React, Material UI, Formik, and Vite.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm

## Getting started

```bash
npm install
npm run dev
```

Vite starts the application at `http://localhost:5173`.

## Commands

```bash
npm run build
npm run preview
```

The starter therapist form currently works locally and does not save data to the backend.
